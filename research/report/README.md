# Complete technical report

- [PDF, 24 pages](report.pdf)
- [Editable Markdown](report.md)

The report covers the completed 22–28 October 2026 investigation: architecture, data preparation, calibration, initialization, execution experiments, three-seed learning comparison, CPU retrieval diagnostic, separate search tuning/confirmation, corrections and final decision.

These are preserved editorial artifacts. `assets/` contains the eight figures referenced by the Markdown. `original_evidence_ledger.json` records the original workspace file identities; the document's historical local paths are not live paths into this reorganized repository. Public numerical exports are under [`../results/`](../results/) and their publication mapping is [`../provenance.json`](../provenance.json).

The original full-report builder required the private research workspace and Windows fonts. It is archived locally rather than presented here as a fresh-clone reproduction command. The report can be read and its principal numerical aggregates checked using [`../summarize.py`](../summarize.py), without claiming a new checkpoint audit or full experiment reproduction.
